# Verification boundaries

The default Vitest suite runs unit/security tests and integration tests against real PostgreSQL and Redis. Dispatcher tests share a database and run files serially; concurrent claims, limits and fencing are explicitly tested inside each case. Use an isolated `uptimeforge_test` database. Redis REST is a test bridge to a real local Redis server; this does not verify the Upstash service.

Playwright starts the optimized Next.js build on localhost, uses real database sessions without an application authentication bypass, and tests desktop and mobile layouts, CRUD/pause, publication/unpublication, privacy, ownership/origin/SSRF rejection, signed check delivery/idempotency and account deletion. The manual worker case performs an actual safe external HTTP request; success, HTTP failure or timeout are all valid persisted endpoint outcomes. QStash signatures use locally generated test keys and the real SDK verifier. No hosted QStash scheduler is exercised.

The E2E server explicitly clears provider publishing/email/OAuth credentials before Next loads local dotenv files, and fixes the database, session secret, signing keys and Redis bridge to test values. A regression test runs the actual Next production env loader with both poisoned inherited credentials and a production dotenv fixture, confirming that secrets stay unavailable and the test database remains selected. The database guard validates the exact pathname and PostgreSQL protocol before starting services. Two earlier local E2E publish attempts inherited hosted QStash credentials and were rejected by the provider with HTTP 400 for localhost callbacks; isolation was fixed and all 8 E2E cases reran without those provider requests. This rejection is not evidence of working production delivery.

Critical coverage includes DNS/IP/redirect validation before connection, pinned DNS and peer verification, incident thresholds, transaction-level duplicate prevention, lease fencing, outbox recovery, unchanged manual scheduling, check-based uptime, active-monitor/status-page limits, publication privacy and retention/account cascades. No artificial coverage percentage is required. The latest code suite contains 125 tests across 24 files, plus 8 desktop/mobile E2E cases. Resend sandbox policy tests cover recipient blocking, no redirection, stale queued delivery and no provider call for disallowed recipients. A QStash identifier regression follows an actual provider HTTP 400 during production smoke.

Email test doubles verify payloads, durable event uniqueness, retry keys and local delivery state; they cannot prove exactly-once delivery by a provider. Uncertain deliveries stop before the provider's 24-hour idempotency horizon and require reconciliation. Account deletion waits for an active sending lease. The app does not claim production readiness from mocks.

CSP restricts frames, objects, forms and connections. Next/next-themes bootstrap scripts still require inline scripts; a nonce policy would require additional cache/runtime validation.

The separate real production smoke verified GitHub OAuth/login/logout/relogin, hosted Neon migrations/TLS/Prisma, Redis operations/rate limiting, QStash scheduled dispatch and signed workers, six actual HTTP checks, incident outage/recovery, duplicate delivery, Resend account-owner Delivered events, public status publication/unpublication and account deletion/cleanup. See [production evidence](production-smoke.md). This production test used no fake authentication or injected check/incident rows.

Remaining production gates are **continuous QStash capacity** and **Resend sending to arbitrary users**. The minute schedule is now paused; only bounded windows were observed. Daily cleanup is configured/enabled and its worker returned 200 through a real QStash call, but its future cron trigger has not yet been observed. Resend has no owned verified domain; sandbox only proves delivery to the account owner. Provider retry/DLQ behavior was not fully exercised with an induced real destination outage. These limits prevent unrestricted production certification despite passing local tests and bounded smoke.
